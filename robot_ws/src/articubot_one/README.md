# articubot_one – hospital delivery robot package

Main ROS 2 package of the robot: URDF/xacro description, launch files, Nav2 and SLAM Toolbox configuration, `twist_mux` priorities and the docking nodes in `scripts/`.

Based on the [articubot_one](https://github.com/joshnewans/articubot_one) template by Josh Newans (Articulated Robotics) and extended for this project. See the [repository README](../../../README.md) for build and run instructions.
